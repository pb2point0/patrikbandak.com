# Healing Journey case study page

## Files to add

Create `/projects/hjw/` in the patrikbandak.com project and copy these files into it:

- `index.html`
- `hjw-case-study.css`
- `hjw-case-study.js`
- the complete `assets/` folder

The page uses the site's existing `/styles.css`, `/js/components.js`, shared header, shared footer, favicon, and logo.

## Add it to the Projects page

Copy the `<article>` from `projects-page-entry.html` into the existing `.project-list` in `/projects/index.html`.

## URLs

- Case study: `/projects/hjw/`
- Public canonical URL: `https://www.patrikbandak.com/projects/hjw/`

## Publishing notes

- Keep the image filenames unchanged unless you also update the paths in `index.html`.
- The page is responsive and the before/after switch works without external libraries.
- With JavaScript disabled, both comparison images remain available.
- No patient records, EHR screenshots, personal health details, or appointment-volume claims are included.
